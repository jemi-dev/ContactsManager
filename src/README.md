# ContactsManager

## Description
Application Java de gestion de contacts permettant d'ajouter
et de rechercher des contacts.

## Structure du projet
- Contact.java : Classe représentant un contact (nom et numéro de téléphone)
- ContactsManager.java : Classe gérant l'ajout et la recherche de contacts
- Main.java : Classe principale contenant le point d'entrée du programme

## Fonctionnalités
- Ajouter un contact
- Rechercher un contact par nom
- Afficher le numéro de téléphone du contact recherché 

## Comment exécuter
- Cloner le dépôt
- Ouvrir le projet dans IntelliJ IDEA ou Un editeur aproprié
- Exécuter la classe Main.java
